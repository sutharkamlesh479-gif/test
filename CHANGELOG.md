# Changelog

## 0.1.0 — Initial MVP

- Static artifact hashing, type hints, printable strings, and partial PE headers.
- JSON/JSONL event normalization, parse-error reporting, and temporal association links.
- File comparison and JSON/HTML reports.
- Loopback-only local browser dashboard.
- Unit tests, GitHub Actions CI, synthetic example logs, and safe-use documentation.

This is an early MVP, not a complete sandbox, decompiler, or antivirus.
